# Neon Overdrive: asset licences (due-diligence list)

|---|---|---|---|
| Cars, city, club, effects | Original (Blender/procedural, this project) | Owned | All names and designs fictional |

| Textures | ambientCG (ambientcg.com) | CC0 | |
| Voices | Kokoro TTS (generated) | Apache-2.0 model; output free to use | assets/voice |
